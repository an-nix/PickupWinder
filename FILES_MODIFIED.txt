KEY CHANGES AT A GLANCE
=======================

1. JSON-RPC Handler Response Time:
   Before: 5-10 seconds (blocking)
   After:  10-50 milliseconds (non-blocking)

2. Concurrent Requests:
   Before: Not possible (sequential)
   After:  Fully supported (parallel)

3. Session Tracking:
   Before: None
   After:  Complete lifecycle (queued/running/completed/failed)

4. New RPC Methods:
   - winder.session.status
   - winder.session.wait

5. Returns from motion commands:
   Before: {blocks_sent: 156}
   After:  {session_id: 1, status: "streaming_started"}
